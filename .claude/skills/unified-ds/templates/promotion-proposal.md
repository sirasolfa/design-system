# 토큰 승격 제안서

> 새 토큰이 필요할 때 채운다. 5조건을 **모두** 만족해야 승인된다. 판정란은 검토자(스킬)가 채운다.

| | |
|---|---|
| 제안 번호 | P-YYYY-NNN |
| 제안일 | YYYY.MM.DD |
| 제안자 | 이름 (역할) |
| 제안 토큰 이름 | `bg/…` — [naming.md](../references/naming.md) 문법 |
| 계층 | Semantic / Module(commerce · messenger) / Brand |
| 의도 | 한 문장 |

## 값

| 모드 | 값 (alias) | 해석값 |
|---|---|---|
| Light | `{…}` | `#RRGGBBAA` |
| Dark | `{…}` | `#RRGGBBAA` |

## 5조건

| # | 조건 | 근거 | 판정 |
|---|---|---|---|
| 1 | 서로 다른 컴포넌트 두 곳 이상에서 같은 의도로 쓰인다 | 컴포넌트명 · 노드 ID 2개 이상 | ☐ |
| 2 | 모드 간 값이 다르거나 기존 토큰과 다른 시점에 바뀔 이유가 있다 | | ☐ |
| 3 | 문법에 맞고 기존 토큰과 의미가 겹치지 않는다 | `lint.py --spec` 결과 · 가장 가까운 기존 토큰 | ☐ |
| 4 | Light · Dark 값이 모두 있고 대비를 통과한다 (텍스트 4.5:1, 아이콘·테두리 3:1) | 조합 · 대비값 | ☐ |
| 5 | 코드가 자동 생성되어 바로 쓸 수 있다 | CSS · TS · Dart 이름 | ☐ |
