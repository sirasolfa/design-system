# 기록 규칙 — Updates · Progress Board · 버전

기록 단계 없이 끝낸 쓰기 작업은 **실패**다. 감사(읽기 전용)만 예외.

## Updates · Changelog

**"업데이트 항목" 컴포넌트 인스턴스로만** 기록한다(텍스트·프레임 직접 작성 금지).
스크립트: [`scripts/figma/write-update.js`](../scripts/figma/write-update.js).

| 필드 | 규칙 |
|---|---|
| 유형 뱃지 | 추가 · 변경 · 이름변경 · 폐기 · 삭제 · 문서 · 릴리스 · 결정 |
| 날짜 | `YYYY.MM.DD` — 작업 완료일 또는 배포일 |
| 타이틀 | `유형 · 한 줄 요약` |
| 상세 | 무엇이 어떻게 바뀌었는지 + 영향 토큰 · 컴포넌트 목록. 값 변경은 `이전 → 새 값`, 폐기는 대체 토큰 |
| 범위 | Primitive / Brand / Semantic / Module / 컴포넌트명 / 문서 페이지명 / 코드(React · Flutter). 복수 가능(` · ` 구분) |
| 비고 | 버전, 결정 안건 번호, 링크, 후속 조치. 없으면 **"없음"** (빈칸 금지) |
| 수정자 | 이름과 역할. 스킬 작성은 **`unified-ds 스킬 (요청자: 이름)`** |

- **쓰기 작업 1회 = 항목 1건.** 여러 컬렉션을 한 번에 만들어도 1건, 상세에 나열한다.
- 최신이 위, **월 섹션**(`YYYY.MM`) 단위.
- **추가만 한다.** 정정은 `변경 · (원래 타이틀) 정정` 항목을 새로 쓴다.
  기존 항목의 삭제 · 수정은 "반드시 확인" 범위.
- 승격 검토는 승인 · 반려 모두 **결정** 항목. 승인 후 실제 생성은 별도 **추가** 항목.
- 코드 내보내기는 **릴리스** 항목, 비고에 버전(`v1.3.0`).

### 예시

```
[추가] 2026.11.09
추가 · Semantic 최소 세트 42개 생성
상세: semantic 컬렉션(Light · Dark)에 bg 20 · fg 13 · stroke 9 생성. 값은 primitive · brand alias.
      scope 지정, ALL_SCOPES 없음. 대비 22쌍 × 4조합 통과.
범위: Semantic
비고: 후속 — 컬러칩 문서 갱신은 다음 항목
수정자: unified-ds 스킬 (요청자: 김시라)
```

```
[변경] 2026.11.10
변경 · fg/brand 값 조정
상세: fg/brand Dark  {brand.primary.300} → {brand.primary.200}  (대비 4.1 → 5.3)
범위: Semantic
비고: patch v1.3.1
수정자: 강희정 (디자이너)
```

## Progress Board

**"진행 행" 컴포넌트 인스턴스로만** 기록한다.
스크립트: [`scripts/figma/write-progress.js`](../scripts/figma/write-progress.js).

| 필드 | 종류 | 값 |
|---|---|---|
| 항목 | 텍스트 | 토큰 그룹 · 컴포넌트 · 문서 · 코드 단위 (행 식별자) |
| 종류 | 텍스트 | 토큰 / 컴포넌트 / 문서 / 코드 |
| 담당자 | 텍스트 | |
| 최종 갱신일 | 텍스트 | = 최근 Updates 항목 날짜 |
| 링크 | 텍스트 | = 최근 Updates 항목 **타이틀** |
| 상태 | 뱃지 | 예정 · 진행중 · 완료 · 보류 |
| Figma · React · Flutter | 뱃지 | 미착수 · 진행 · 반영 · 검증 완료 |

- Updates 항목이 생길 때마다 **영향 행**의 상태 · 갱신일 · 링크를 갱신하고, 없으면 새 행을 만든다.
- 종류 → 그룹 프레임: 토큰 → `Foundation — 토큰`, 컴포넌트 → `컴포넌트`, 문서 · 코드 → `문서 · 코드`.
- 로드맵 보드의 **업무 카드** 상태와 같이 움직인다(카드 `타이틀` = 행 `항목`).

### 플랫폼 상태 전이

| 작업 | Figma | React | Flutter |
|---|---|---|---|
| 토큰 생성 · 변경 | 반영 | (그대로) | (그대로) |
| 코드 내보내기 | | 반영 | 반영 |
| 개발자 확인 | | 검증 완료 | 검증 완료 |
| 컴포넌트 통합(스텁만) | 반영 | 진행 | 진행 |

## 동기화

- 사람이 Figma 에서 직접 고친 변경도 **같은 규칙**으로 기록한다(수정자 = 그 사람).
- 감사는 Updates 에 없는 변수 diff 와 수정자 빈 항목을 **"기록 누락"** 으로 보고한다
  ([`scripts/audit_log.py`](../scripts/audit_log.py) `--diff`).
- `CHANGELOG.md` 와 두 페이지가 다르면 **Updates 가 맞다.** `CHANGELOG.md` 를 다시 생성한다
  ([`scripts/changelog.py`](../scripts/changelog.py)).

## 버전 규칙 (토큰 패키지 semver)

| 변경 | 올림 |
|---|---|
| 이름 삭제 · 의미 변경 · 이름변경 | **major** (사용자 확인 필요) |
| 토큰 추가 | minor |
| 값 변경 | patch |

**폐기 절차** — `$description` 에 `Deprecated → 대체 토큰` 을 적고, 코드 alias 를 남긴 채
**두 릴리스 뒤** 삭제한다. 폐기 시점 Updates **폐기** 항목, 삭제 시점 **삭제** 항목(major).

## 값 포맷

| 종류 | 포맷 |
|---|---|
| 색 | `#RRGGBBAA` |
| 숫자 | 단위 없는 논리 픽셀 (CSS 생성 시 `px`, duration 은 `ms`) |
| 폰트 | family 문자열 |
